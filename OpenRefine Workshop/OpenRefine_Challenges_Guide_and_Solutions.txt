Use these files

Faceting challenges: census_and_trends_data_OpenRefine.csv

Import each CSV as a separate OpenRefine project. Keep the original column names and values while investigating. These exercises are about finding and interpreting inconsistent data; do not replace values unless the challenge explicitly asks you to merge text clusters.

FACETING PRACTICE

1. Alien Impostors

Challenge
Find the numeric column containing the most text values that do not belong. How many errors can you find in one column?

Steps
1. Open the census project and inspect numeric columns, especially the population and demographic fields.
2. Use a numeric facet or type-based facet to find cells OpenRefine does not recognize as numbers.
3. Add a text facet to the leading candidate. Review the exact values and their counts.
4. Distinguish malformed text from legitimate numeric formatting, such as a population with thousands separators.

Answer key
The intended column is total_pop. It has eight suspicious text entries:

- Alaska: about 733406
- Delaware: about 1031890
- Massachusetts: —
- New York: 19571216 people
- North Dakota: 783926%
- Ohio: ~11785935
- Washington: approx. 7812880
- blank state: unknown

These are eight different suspicious forms. A comma-formatted population such as 38,965,193 is still a numeric value that can be parsed; check how the facet interprets it before counting it as an error.

2. Escape-Velocity Outliers

Challenge
Through all of the sports columns, find values greater than the expected 0–100 range. Which column has the biggest problem?

Steps
1. In the census project, inspect the sports columns from basketball through water polo.
2. Create a numeric facet for a sports column and inspect its maximum, or use a text facet to find unusually large numeric-looking entries.
3. Repeat across the sports columns. Record the column, state, and value for each value above 100.
4. Compare both the largest value and the number of outliers in each column.

Answer key
There are 19 numeric values above 100 across 17 sports columns. The largest is badminton = 8920 for New Hampshire. Baseball and bowling have the most above-range values, tied at two each:

- baseball: Louisiana 231; South Dakota 7519
- bowling: Kansas 272; Alabma 921

The other above-range values are basketball 7267 (Maryland), hockey 2201 (Mississippi), pickleball 7070 (Indiana), snowboarding 3698 (Arizona), nba 8548 (Minnesota), nhl 5559 (Iowa), march madness 8551 (Arkansas), pga tour 1573 (Connecticut), nascar 2065 (Pennsylvania), volleyball 4665 (Mississippi), gymnastics 7055 (Georgia), lacrosse 4100 (Illinois), archery 2304 (New Mexico), skateboarding 4447 (blank state), and badminton 8920 (New Hampshire).

If “biggest problem” means the most extreme single value, the answer is badminton. If it means the highest count of out-of-range cells, baseball and bowling tie. Values outside 0–100 should be flagged for review; do not infer their intended replacements from this dataset alone.

3. The Data Wormhole

Challenge
Go through a column that uses true/false values. Count how many variations of true there are and how many variations of false.

Steps
1. In the census project, choose a Boolean-style column such as has_waffle_house.
2. Create a text facet and sort by name so capitalization, whitespace, and alternate representations appear separately.
3. Count the distinct forms that appear to mean true and false. Repeat for the other Boolean-style columns and compare.
4. Treat the semantic meaning of values such as YES and 0 as a data rule to confirm, not something OpenRefine can decide automatically.

Answer key
In has_waffle_house, the three apparent true forms are TRUE, True, and YES. The six apparent false forms are FALSE, false, False, False with trailing whitespace, NO, and 0. Exact spelling and capitalization matter in the text facet.

Across the four Boolean-style columns (has_nba_team, has_major_zoo, is_coastal, and has_waffle_house), the same general forms occur, with small differences by column. NO and 0 appear as false-like values; YES appears as a true-like value. Confirm those mappings before transforming the data.

CLUSTERING CHALLENGES

Use the space practice dataset for all three challenges. To inspect a column, use its dropdown menu and choose Edit cells → Cluster and edit. Review proposed clusters before merging. The exact suggestions can vary with method and settings.

1. The Planet of Many Names

Challenge
Find the planet with the most spelling and formatting variations. Merge its identities into one official name.

Steps
1. Create a text facet on Planet and inspect the distinct values.
2. Open Cluster and edit. Start with Key collision → Fingerprint to find case and spacing variations.
3. Review a cluster, choose the official spelling shown below, and merge only the records that clearly represent the same planet.
4. Use a small-radius nearest-neighbor method to explore additional close spellings, reviewing every suggestion.

Answer key
The data has 86 distinct Planet strings representing 15 apparent planet names. There is not one unique winner: 11 planet families tie with six distinct forms each (Asgard, Coruscant, Earth, Gallifrey, Mandalore, Naboo, Pandora, Qo'noS, Tatooine, Vulcan, and Xandar). Ego, Hoth, Krypton, and Romulus each have five forms. For a demonstration, merge the six Vulcan forms to the official name Vulcan.

The differences are capitalization and, in some cases, trailing whitespace. This dataset does not contain a unique planet with more spelling errors than all the others; make that tie clear to learners.

2. The Space Food Fiasco

Challenge
On the Main Food Dish column, use different clustering methods and see which one finds more spelling mistakes.

Steps
1. Open Cluster and edit on Main Food Dish.
2. Run Key collision → Fingerprint and note which capitalization and spacing variants it groups.
3. Compare with a nearest-neighbor method, such as N-gram Fingerprint or Levenshtein. Try a conservative setting first.
4. Review the suggested clusters and count plausible spelling mistakes separately from simple case or whitespace differences.

Answer key
Most differences are capitalization and trailing spaces. A likely spelling issue is Ail Soup / ail soup in comparison with Ale Soup / ale soup. A nearest-neighbor method may surface Ail Soup as a candidate for Ale Soup, while Fingerprint keeps the different spellings apart. Treat this as a review candidate; confirm the intended dish before merging. There are 62 distinct raw strings in the column, including these variants, and the number of suggestions depends on the clustering method and settings.

3. Cluster Constellation

Challenge
Using the Favorite Activity column, see how many errors you can find in variations of the planets’ favorite things.

Steps
1. Open Cluster and edit on Favorite Activity.
2. Start with Fingerprint to find case, spacing, and punctuation variants.
3. Compare with N-gram Fingerprint or Levenshtein to find looser matches.
4. Inspect each cluster, record the distinct forms, and merge only forms that clearly represent the same activity.

Answer key
Favorite Activity contains 68 distinct raw strings and 15 apparent activity labels. The differences are mostly capitalization, trailing spaces, or hyphenation. Eight activities have five raw forms each: Armor Crafting, Bat'leth Training, Ice Sculpting, Logic Debates, Pod Racing, Star Racing, Time Travel, and Tree Climbing. The other seven labels have four forms each: Boating, Espionage, Feasting, Flying, Gaming, Meditation, and Politics.

The dataset supplies formatting variants rather than a single definitive list of misspellings. Clustering can suggest which forms to review, but learners should not count a punctuation or case difference as a proven content error. Use consistent official spellings when merging.

Instructor note
Clustering algorithms produce candidate groups, not verified corrections. Keep the original project or a copy before merging, and use an authoritative source when the intended value is uncertain.
