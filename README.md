This repo is for data workshop students to be able to quickly locate example code and datasets

Each workshop has its' own folder within the repository, along with some slides and examples that instructors may have used in the workshops.

The csv for each workshop may be imported to its respective program (openrefine, rstudio, etc) by using the link to the raw data. This can be found by clicking on the file, and then clicking raw, or the link can be found in the readme within each folder.

The example code can be copied and pasted, or downloaded and opened in its respective program.
